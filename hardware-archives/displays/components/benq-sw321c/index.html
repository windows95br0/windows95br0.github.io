BenQ PhotoVue SW321C

31.5-inch 4K photo-editing LCD with Adobe RGB coverage, hardware calibration and 60 W USB-C.

IDENTIFICATION: BenQ model PhotoVue SW321C. Confirm the full rear-label model, region and hardware revision; published capabilities can differ by firmware, input board and bundle.

Compatibility and deployment

Native 4K/60 Hz operation requires a source and cable supporting the selected DP 1.4, HDMI 2.0 or USB-C DP Alt Mode signal. Confirm host USB-C power needs against its own adapter; use BenQ calibration software and a supported sensor for monitor hardware calibration.

Preservation notes

Record the complete rear-label SKU, serial/date code, installed firmware and options, calibration report, supported signal timing, tested source and cable, mounting hardware, regional AC rating and image condition. Keep the original hood/stand and model-specific setup documentation with the display; use trained service personnel for internal work.
