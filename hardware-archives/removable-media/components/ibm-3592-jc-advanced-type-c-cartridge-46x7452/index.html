IBM 3592 JC Advanced Type C Data Cartridge (46X7452)

This entry identifies the removable medium SKU, not its drive or dock. Confirm the exact model label, medium generation, host format and drive/dock compatibility before use.

IDENTIFICATION: IBM manufacturer SKU 46X7452; IBM 3592 Advanced Type C (JC) enterprise tape cartridge. Native capacity is distinguished from any data-dependent compression estimate.

Capacity, physical format and compatibility

Manufacturer / SKUIBM 46X7452
Medium / generationIBM 3592 Advanced Type C (JC) enterprise tape cartridge; Type C / 3592 JC medium generation, 12.7 mm half-inch-class enterprise magnetic tape with cartridge memory.
Native capacity4 TB native in E07/TS1140 format or 7 TB in E08/TS1150 format; compression is content-dependent.
Drive/dock compatibilityIBM TS1140 and TS1150 systems as specified by IBM; Type JC is 4 TB in E07 format and 7 TB in E08 format. Do not assume support in another drive or library without its media matrix.
Physical mediumRigid single-reel enterprise cartridge with leader, protective shell, write-protect control and embedded cartridge-memory chip; 12.7 mm wide magnetic tape.
Electrical interfaceNo host data/power connector. A compatible IBM 3592 drive engages tape and contacts the cartridge-memory interface; the drive/library host bus (such as Fibre Channel) is separate.
Format limitsThe JC label identifies media generation, not one fixed effective capacity: capacity and write access depend on drive, format and firmware. It is not LTO, DLT or 3592 JA/JB media.

Storage and preservation cautions

Keep in its case, clean, cool and dry; avoid dust, sunlight, strong magnetic fields and sudden environmental changes. Handle the shell only, acclimatize before loading, verify checksums and migrate data to independent copies while compatible readers remain available.

  • Do not force media into a drive/dock or use improvised cleaners, lubricants or repairs. Stop if the shell, connector, tape leader or disk enclosure is damaged.
  • Preserve more than one independent copy, verify checksums after transfer, and document the drive/dock, firmware, OS and format used. Plan migration before compatible equipment is lost.
