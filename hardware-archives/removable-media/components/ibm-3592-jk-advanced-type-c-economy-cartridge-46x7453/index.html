IBM 3592 JK Advanced Type C Economy Data Cartridge (46X7453)

This entry identifies the removable medium SKU, not its drive or dock. Confirm the exact model label, medium generation, host format and drive/dock compatibility before use.

IDENTIFICATION: IBM manufacturer SKU 46X7453; IBM 3592 Advanced Type C Economy (JK) enterprise tape cartridge. Native capacity is distinguished from any data-dependent compression estimate.

Capacity, physical format and compatibility

Manufacturer / SKUIBM 46X7453
Medium / generationIBM 3592 Advanced Type C Economy (JK) enterprise tape cartridge; Type C Economy / 3592 JK media generation; 12.7 mm half-inch-class enterprise magnetic tape with cartridge memory.
Native capacity900 GB native in TS1150 (E08) format; some earlier or later drive formats expose a different capacity. Compression is data-dependent.
Drive/dock compatibilityIBM TS1140 and TS1150 systems that list JK; TS1140 E07 formatting is 500 GB native, while TS1150 E08 formatting is 900 GB. Verify exact drive/firmware support.
Physical mediumRugged sealed IBM 3592 cartridge with leader, write-protect control and embedded cartridge memory; 12.7 mm-class tape.
Electrical interfaceNo host-facing data/power connector; the compatible drive transports tape and accesses cartridge memory. Drive/library host interface is separate from this medium.
Format limitsJK is economy media and is not the higher-capacity JC cartridge. Native capacity depends on 3592 drive format (500 GB E07 or 900 GB E08); it is not interchangeable with LTO media.

Storage and preservation cautions

Retain case and label; store in a stable, clean, dry location away from strong magnetic fields, contaminants, sunlight and sharp temperature/humidity changes. Acclimatize before loading; preserve multiple independently verified copies and a compatible reader.

  • Do not force media into a drive/dock or use improvised cleaners, lubricants or repairs. Stop if the shell, connector, tape leader or disk enclosure is damaged.
  • Preserve more than one independent copy, verify checksums after transfer, and document the drive/dock, firmware, OS and format used. Plan migration before compatible equipment is lost.
