Intel Ethernet Controller I210-AT

Single-port Gigabit Ethernet controller IC for PCIe-based motherboard and adapter designs. This is a controller/chip record; finished-card details are implementation-specific.

IDENTIFICATION: Match complete component top-mark, stepping and board revision. Nominal signaling rates are not measurements of application throughput.

Exact specifications and compatibility

Dedicated subcategoryEthernet controllers and PHYs
Exact controller identityIntel Ethernet Controller I210-AT
Component / board identityController IC with integrated 10/100/1000 Ethernet MAC/PHY; board supplies RJ-45 and magnetics.
PCIe bus and host interfacePCI Express 2.1 x1 host interface.
Ethernet ports / physical interfaceOne 10/100/1000BASE-T twisted-pair Ethernet port; link partner negotiation and cable determine the negotiated rate.
Nominal rate (not measured)Up to 1 Gb/s nominal on one port; not measured throughput.
Drivers and OS compatibilityLinux igb driver; Intel/OEM Windows Ethernet driver packages support selected versions. Confirm PCI ID, OS release, board NVM and OEM support list before deployment.
Board / system compatibilityRequires an I210-AT-compatible host board with PCIe x1 routing, clocks, power, NVM and the analog/magnetics layout specified by Intel. The IC alone is not an add-in NIC.
Revision and variant warningI210-AT is a copper PHY/controller variant. Do not conflate it with I210-IS or a retail I210-T1 board; packages, temperature range and board design differ.
Measured throughputNo measured benchmark is claimed for a physical specimen. A valid result records the host, link partner, medium, driver/firmware, traffic pattern, test tool and duration.

Identification and revision notes

I210-AT is a copper PHY/controller variant. Do not conflate it with I210-IS or a retail I210-T1 board; packages, temperature range and board design differ.

Linux igb driver; Intel/OEM Windows Ethernet driver packages support selected versions. Confirm PCI ID, OS release, board NVM and OEM support list before deployment.

Requires an I210-AT-compatible host board with PCIe x1 routing, clocks, power, NVM and the analog/magnetics layout specified by Intel. The IC alone is not an add-in NIC.

Archival and preservation notes

Photograph the package top mark and board silkscreen; record stepping, PCI vendor/device/subsystem IDs, NVM and the exact OEM driver package.

For an installed specimen, preserve source URL, access date, source revision and label/condition notes. Do not infer connector count or board-level compatibility from controller family name alone.
