GIGABYTE GA-H170N-WIFI (Rev. 1.0)

LGA1151 H170 Mini-ITX board with onboard Wi-Fi and Bluetooth. This specification is limited to GA-H170N-WIFI Rev. 1.0; processor support and firmware are revision-specific.

IDENTIFICATION: Confirm the complete model suffix and PCB revision printed on the board. Select firmware and parts from the documentation for this exact revision; a matching socket or product family alone does not establish compatibility.

Specifications

Exact model / PCB revisionGIGABYTE GA-H170N-WIFI (Rev. 1.0)
Processor / socketLGA1151 socket for supported 6th-generation Intel Core, Pentium and Celeron processors; selected 7th-generation CPUs require a BIOS update. Use the model-specific CPU list to identify minimum firmware.
ChipsetIntel H170 Express.
Form factorMini-ITX, 170 × 170 mm.
Memory and slotsTwo DDR4 dual-channel UDIMM sockets, up to 32 GB; DDR4-2133 base platform support, non-ECC unbuffered memory; memory profiles do not override CPU/chipset limits.
ExpansionOne PCIe 3.0 x16 slot; rear M.2 Socket 3 for supported SATA/PCIe SSD and separate wireless M.2 interface/onboard radio.
StorageSix SATA 6 Gb/s connectors, two SATA Express connectors, and rear-side M.2 Socket 3 SSD connector (2260/2280); consult the manual for shared SATA lanes and RAID configuration.
Network and onboard I/ODual Intel Gigabit Ethernet controllers, onboard dual-band 802.11ac Wi-Fi and Bluetooth, external antenna connectors; Realtek HD audio and CPU-dependent video outputs.
Power connections24-pin ATX main connector and CPU ATX12V/EPS power input; consult the Rev. 1.0 manual for exact connector placement/pin count and the system PSU rating.
BIOS / firmwareGIGABYTE AMI UEFI DualBIOS. The 7th-gen LGA1151 CPU family needs a compatible BIOS; verify minimum version and update process before changing CPU.
Enclosure compatibilityMini-ITX 170 × 170 mm chassis pattern. Check GPU/cooler clearances, the rear-side M.2 socket service access, Wi-Fi antenna routing, and airflow for installed CPU and storage.

Compatibility and revision notes

The board has both M.2 storage and wireless connectivity; these are different functions. Lane sharing and drive population can affect available SATA ports, so follow the revision-specific storage table.

Before assembly, verify the exact CPU support list and minimum firmware, memory generation and population order, storage lane sharing, add-in card dimensions, chassis standoffs and PSU leads in the cited revision-matched manual. Observe ESD precautions and never update with firmware for a similarly named board.

Installation and preservation

Inspect the PCB revision silkscreen, socket or soldered processor, memory slots, power connectors, storage sockets and rear-I/O ports before use. Record BIOS version, date/serial identifiers, installed accessories and test conditions; keep the board manual and firmware tied to its exact model and revision.
