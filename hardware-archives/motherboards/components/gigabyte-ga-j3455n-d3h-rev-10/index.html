GIGABYTE GA-J3455N-D3H (Rev. 1.0)

Fanless Mini-ITX board using a soldered Intel Celeron J3455 Apollo Lake SoC. This record is for GA-J3455N-D3H Rev. 1.0 only; the legacy PCI slot and dual-LAN hardware are distinguishing features.

IDENTIFICATION: Confirm the complete model suffix and PCB revision printed on the board. Select firmware and parts from the documentation for this exact revision; a matching socket or product family alone does not establish compatibility.

Specifications

Exact model / PCB revisionGIGABYTE GA-J3455N-D3H (Rev. 1.0)
Processor / socketIntel Celeron J3455 Apollo Lake quad-core SoC, up to 2.3 GHz; soldered BGA package, no CPU socket.
ChipsetApollo Lake SoC platform; core system I/O is integrated in the J3455 rather than a separate chipset.
Form factorMini-ITX, 170 × 170 mm.
Memory and slotsTwo DDR3L SO-DIMM slots, dual-channel, up to 16 GB total, non-ECC; DDR3L 1866/1600/1333 MT/s supported as constrained by the onboard memory controller.
ExpansionOne conventional PCI slot; no PCIe x1/x16 slot on this model. Check legacy-card electrical and bracket compatibility before installation.
StorageFour SATA 6 Gb/s ports (two from the SoC and two through the onboard ASMedia controller).
Network and onboard I/OTwo Realtek Gigabit Ethernet controllers; onboard audio and J3455 integrated Intel HD Graphics 500 with HDMI and D-Sub outputs.
Power connections24-pin ATX main power and 4-pin ATX12V input per board layout; use the matching manual for header location and PSU requirements.
BIOS / firmwareGIGABYTE UEFI DualBIOS for GA-J3455N-D3H Rev. 1.0. The J3455 is soldered and cannot be upgraded; use only the Rev. 1.0 BIOS and support files.
Enclosure compatibility170 × 170 mm Mini-ITX; compatible with a standard Mini-ITX chassis that has matching standoffs, rear-I/O opening, passive cooling clearance, and a slot opening for a legacy PCI card.

Compatibility and revision notes

The expansion slot is full legacy PCI, not PCI Express. The two additional SATA connectors use an auxiliary controller, so storage detection and driver requirements can differ from native SoC SATA.

Before assembly, verify the exact CPU support list and minimum firmware, memory generation and population order, storage lane sharing, add-in card dimensions, chassis standoffs and PSU leads in the cited revision-matched manual. Observe ESD precautions and never update with firmware for a similarly named board.

Installation and preservation

Inspect the PCB revision silkscreen, socket or soldered processor, memory slots, power connectors, storage sockets and rear-I/O ports before use. Record BIOS version, date/serial identifiers, installed accessories and test conditions; keep the board manual and firmware tied to its exact model and revision.
