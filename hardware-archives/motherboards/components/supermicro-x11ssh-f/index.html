Supermicro X11SSH-F

LGA1151/C236 server board for Xeon E3 v5/v6, ECC UDIMM, SATA and IPMI. This record is restricted to the exact printed SKU; confirm the physical PCB revision before installation or firmware service.

Compatibility and revision notes

Use X11SSH-F CPU list and minimum BIOS for supported CPU generation/stepping; firmware for a related model is not a substitute. Populate memory only in the documented module class and channel order; ECC does not make UDIMM/RDIMM classes interchangeable. Check chassis clearance, cooler, power connectors, risers, storage cabling and BMC network isolation against the model manual.

Socket shape and chipset branding alone do not guarantee CPU compatibility. Confirm exact CPU/stepping, minimum BIOS, memory QVL, PCIe lane sharing and board revision before service.

Preservation and repair

Record PCB silk-screen, serial label, BIOS/BMC versions, MAC addresses, attached risers and cables, and test conditions. Use ESD-safe handling and the vendor socket procedure; never apply firmware for a visually similar SKU.
