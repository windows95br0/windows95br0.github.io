ASRock X570 Taichi Razer Edition

AMD X570 Socket AM4 2021 enthusiast desktop board. This static record describes this exact model and revision only; confirm the printed PCB identity and use the cited manufacturer's support files.

REVISION / FIRMWARE WARNING: Similar model names, PCB revisions and regional SKUs may differ in connectors, radio hardware and firmware. Identify the exact board printed on the PCB before selecting a BIOS.

Specifications

Exact model / generationASRock X570 Taichi Razer Edition — 2021 enthusiast desktop board
ChipsetAMD X570
CPU socket / supportSocket AM4; processor families and minimum BIOS are limited to the exact manufacturer CPU support list.
Form factorATX, 305 × 244 mm
Memory supportFour dual-channel DDR4 DIMM slots; up to 128 GB. Supported speeds and ECC operation depend on CPU, BIOS, module population and ASRock QVL.
PCI Express expansionThree x16-length slots; the primary CPU slot supports PCIe 4.0, while remaining link widths/generation and x8/x8 sharing depend on the CPU and slot. Two PCIe x1 slots are also provided.
StorageTwo M-key storage M.2 sockets (PCIe 4.0 x4; the lower socket has chipset-dependent mode) and eight SATA 6 Gb/s ports. A separate Key-E socket is for wireless module, not an SSD.
Rear I/O and networkRear USB 3.2 Gen 2 Type-A/Type-C plus USB 3.2/2.0, HDMI for compatible APU, 2.5GbE and Gigabit Ethernet, Wi-Fi 6 antenna connectors and onboard audio. Razer Chroma integration is a board feature, not a separate Wi-Fi SKU.
BIOS / manufacturer supportASRock UEFI support includes model-specific BIOS, manuals and CPU list; the board provides BIOS Flashback. Verify current CPU and minimum firmware before upgrade; firmware for the standard X570 Taichi is not interchangeable by name alone.

Compatibility and installation notes

Check exact Taichi Razer Edition identity, CPU support, PCIe lane sharing and M.2/SATA interaction in its manual. DDR4 is required. The board does not supply integrated graphics; monitor output requires a compatible APU, otherwise install a discrete graphics card.

Before assembly, confirm board revision, chassis dimensions/standoffs, CPU cooler mount and power leads in the manual. Never infer processor compatibility from the physical socket alone. For memory, follow the documented population order and consult the exact board's QVL; EXPO/XMP and other overclocked speeds are not guaranteed.

Read the lane-sharing tables before installing expansion cards and drives. Observe ESD precautions, protect socket contacts, and record the installed BIOS revision and any update history.

Preservation and service

Inspect the socket, DIMM slots, power connectors, M.2 thermal hardware and capacitors before use. Record PCB revision and serial/date codes, document repairs and test conditions, and retain model-matched manual and firmware files. Do not cross-flash firmware from a similarly named board.
