DDR5-4800 262-pin SO-DIMM

DDR5 SO-DIMM standard speed class. This record identifies a distinct product or standards-defined module class; specifications not verified for this exact identity are deliberately left open.

IDENTITY: DDR5-4800 262-pin SO-DIMM is cataloged as ddr5 so-dimm standard speed class. Standards entries describe a module class; named manufacturer entries describe one SKU. Do not treat them as interchangeable records.

Verified specifications262-pin SO-DIMM; DDR5-4800 (4800 MT/s) baseline data-rate class; 1.1 V nominal. Module capacity, organization, ranks, timings, and ECC status are model-dependent. On-die ECC is not host-visible system ECC.

Unverified/variable detailsOnly values supported by the cited standard or manufacturer source are stated. Confirm exact part number/revision, SPD, ranks, timings, and voltage on the specimen when not specified above.

Platform compatibility and service

  • Requires a DDR5 SO-DIMM socket and DDR5-capable memory controller/firmware. DDR5 and earlier SO-DIMMs are electrically and mechanically incompatible. Confirm platform support for module density and capacity.
  • Before installation, record the full label, manufacturer, part number, revision/date code, contact condition, chip markings, and SPD contents where present.
  • Use ESD precautions, handle the module by its edges, and never force it into a slot with different keying. Power down and follow the host’s service manual.
  • For server/ECC modules, confirm CPU support, buffering type, channel population, supported ranks/densities, and firmware behavior; physical fit is not proof of ECC operation.

Archival and service notes

Standards class only, not a vendor product. Preserve part label and SPD data; do not infer system ECC capability from DDR5 on-die error correction. Photograph both sides before cleaning; retain the host manual, SPD dump, test host, BIOS revision, and memory-test result with the catalog record.
