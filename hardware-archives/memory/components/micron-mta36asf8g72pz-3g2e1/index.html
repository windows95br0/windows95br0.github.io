[ MICRON // MODEL RECORD ]

MTA36ASF8G72PZ-3G2E1

A 64 GB Micron DDR4-3200 ECC Registered DIMM for qualified enterprise hosts. This high-density module requires the server's memory controller and board to support its capacity, organization and registered interface.

Model specifications

Capacity / module64 GB; 288-pin DDR4 DIMM
Rank / chip organization2Rx4 dual rank; 8G x72 module organization, x4 DRAM devices, with a 64-bit data path plus 8 ECC bits.
Speed / JEDECDDR4-3200, 3200 MT/s (PC4-25600R); JEDEC CL22 at nominal 1.2 V.
Voltage1.2 V nominal VDD/VDDQ.
ECC / bufferingECC Registered DIMM (RDIMM) with registered command/address signaling.
Platform compatibilityNeeds a platform qualified for 64 GB 2Rx4 DDR4 RDIMMs and 3200 MT/s. Intel Xeon Scalable 3rd Gen supports DDR4-3200; exact usable rate and capacity depend on server board, CPU, DIMMs per channel, firmware and QVL. Check the specific system manual; CPU-family support alone is not SKU-level qualification.

Service and compatibility notes

  • Do not mix with unbuffered or load-reduced memory unless explicitly supported by the host.
  • Validate supported device density and rank against the server's memory population guide and service parts list.
  • Preserve the exact label, SPD contents, slot identity and ECC/error logs for future diagnosis.
