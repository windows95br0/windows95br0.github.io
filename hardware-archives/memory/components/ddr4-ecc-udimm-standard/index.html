DDR4 ECC UDIMM (288-pin)

DDR4 ECC unbuffered DIMM module class. This record identifies a distinct product or standards-defined module class; specifications not verified for this exact identity are deliberately left open.

IDENTITY: DDR4 ECC UDIMM (288-pin) is cataloged as ddr4 ecc unbuffered dimm module class. Standards entries describe a module class; named manufacturer entries describe one SKU. Do not treat them as interchangeable records.

Platform compatibility and service

  • Requires a CPU memory controller and motherboard/firmware that support ECC UDIMMs. A board may physically accept a DIMM yet disable ECC or reject the module. Never substitute registered modules unless platform documentation explicitly permits them.
  • Before installation, record the full label, manufacturer, part number, revision/date code, contact condition, chip markings, and SPD contents where present.
  • Use ESD precautions, handle the module by its edges, and never force it into a slot with different keying. Power down and follow the host’s service manual.
  • For server/ECC modules, confirm CPU support, buffering type, channel population, supported ranks/densities, and firmware behavior; physical fit is not proof of ECC operation.

Archival and service notes

This names a module type, not a specific capacity or maker. Verify ECC reporting in firmware/OS and distinguish system-level ECC from DDR5 on-die ECC. Photograph both sides before cleaning; retain the host manual, SPD dump, test host, BIOS revision, and memory-test result with the catalog record.
