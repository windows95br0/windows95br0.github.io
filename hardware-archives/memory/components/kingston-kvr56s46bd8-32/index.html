[ KINGSTON VALUERAM // DDR5 MEMORY ]

Kingston ValueRAM KVR56S46BD8-32

An individual 32 GB dual-rank DDR5-5600 SO-DIMM, distinct from Kingston's single-rank 32 GB model. Rank and timing values are specified for this exact SKU.

Model specifications

Exact part / capacityKingston ValueRAM KVR56S46BD8-32; 32 GB
Form factor / rank262-pin DDR5 SO-DIMM; dual rank, 2Rx8
Speed / profileDDR5-5600 (PC5-5600), JEDEC timing 46-45-45 (CL46). SPD is programmed for this JEDEC profile; no XMP or EXPO profile is specified.
Voltage1.1 V operating module voltage
ECC / bufferingNon-ECC, unbuffered client module. DDR5 on-die ECC is present in the memory devices; it is not system-level ECC.

Compatibility guidance

  • Requires a 262-pin DDR5 SO-DIMM host; DDR4 modules and desktop DIMMs are incompatible.
  • Confirm the laptop supports 32 GB capacity, dual-rank x8 organization and the module density. Firmware may limit the rate or maximum memory recognized.
  • JEDEC SPD supplies DDR5-5600 timing; no XMP/EXPO profile is specified. Host controller support determines the configured speed.
  • Follow the notebook's slot population and installation guidance, including power isolation and ESD handling. Mixed modules can train at a lower shared rate.
