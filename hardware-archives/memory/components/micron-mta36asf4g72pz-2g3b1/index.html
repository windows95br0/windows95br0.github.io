[ MICRON // MODEL RECORD ]

MTA36ASF4G72PZ-2G3B1

A 32 GB Micron ECC Registered server module identified by its complete part number. This 2400 MT/s generation-4 DIMM is intended for platforms that specifically support RDIMMs.

Model specifications

Capacity / module32 GB; 288-pin DDR4 DIMM
Rank / chip organization2Rx4 dual rank; 4G x72 module organization, x4 DRAM devices, 64 data bits + 8 ECC bits.
Speed / JEDECDDR4-2400, 2400 MT/s (PC4-19200R); JEDEC CL17 timing at 1.2 V.
Voltage1.2 V nominal VDD/VDDQ.
ECC / bufferingECC Registered DIMM (RDIMM); command/address signals are registered.
Platform compatibilityRequires a server/workstation board and memory controller supporting 32 GB 2Rx4 ECC RDIMMs. Intel Xeon Scalable 3rd Gen supports DDR4-3200 and may use lower-speed modules at their supported SPD rate; exact behavior depends on host QVL, CPU, firmware and DIMMs per channel.

Service and compatibility notes

  • Do not insert into UDIMM-only or LRDIMM-only systems; registered and ECC capabilities must both match the platform.
  • Check the system manual for maximum rank/density, memory speed under the planned population and required slot order.
  • Keep the SPD dump, label and platform configuration with the archived specimen.
