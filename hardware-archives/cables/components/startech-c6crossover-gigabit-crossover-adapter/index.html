StarTech C6CROSSOVER Gigabit Cat 6 Crossover Adapter

Physical & electrical compatibility

Not a speed converter, switch, or Ethernet isolation device. It changes pair mapping; use only where both endpoint PHYs and the cable channel support the desired Ethernet category. Check port auto-MDI/MDIX and avoid stacking adapters or confusing it with PoE-rated couplers.

Archival & handling notes

Label as an inline crossover adapter and store with any paired patch lead. Record host port types when used; inspect RJ45 contacts and latch for damage before use.

Record provenance, condition, label photographs, exact full part number/revision, host system, and any test method/result. Preserve packaging and source documents with the cable when available.
