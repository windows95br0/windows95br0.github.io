Microsoft Adaptive Hub

Wireless and wired hub for connecting external switches, buttons, and joysticks to compatible hosts.

Physical mechanism and primary specificationsFive 3.5 mm switch ports; three USB-C accessory ports for Microsoft Adaptive Buttons; a separate USB-C charging port; Bluetooth pairing to host devices and three profile slots. Consult the guide for exact port behavior.
Host, interface, and driver caveatsDesigned for Windows 10/11 accessibility use with Microsoft Accessory Center; Bluetooth pairs the hub to the host, while its USB-C accessory ports are for Microsoft Adaptive Buttons. It is not a generic USB hub. Confirm model marking; distinguish from Xbox Adaptive Controller.
