Razer DeathAdder V3 Pro

Lightweight right-handed wireless mouse with Focus Pro 30K sensor and HyperSpeed receiver. This entry identifies this product generation and distinguishes important interface and revision differences.

MODEL IDENTIFICATION: Check the label for the complete model, revision, regional SKU, accessories, and current manufacturer documentation before installation.

Catalog identityRazer DeathAdder V3 Pro
Era / familyWireless right-handed esports mouse, 2022 generation
Product-specific featuresFocus Pro 30K optical sensor; five-button design; approx. 63 g black / 64 g white; vendor-rated battery up to 90 h under stated conditions.
Interface2.4 GHz HyperSpeed USB receiver; USB-C cable for wired use/charging. Bluetooth is not provided. HyperPolling receiver is a separate accessory.
Compatibility guidanceBasic pointing works over USB receiver; DPI, profiles, and firmware use Razer Synapse on supported OS. Keep the model-paired receiver; optional higher polling needs separate compatible hardware.
