Compatibility, installation & service

  • Verify M-key PCIe/NVMe wiring, M.2 2280 standoff and UEFI boot support in the host manual. Check lane sharing and board thermal-pad arrangement; do not cover the drive with a heatsink that lacks contact or adequate clearance. Check SMART health and firmware with current SanDisk/WD support tools and keep a backup before any update or replacement.
  • Confirm the complete WDS100T3B0C product code and label. It is a Gen3 NVMe M.2 device, not SATA M.2. A higher-generation host will negotiate a lower Gen3 link; booting is controlled by platform UEFI and OS support.
  • Confirm host boot mode, OS NVMe support, CPU lane generation, socket length/keying, power and controller/backplane qualification from the system manual; physical fit alone does not establish compatibility.
  • Before drive replacement, check backup integrity, encryption keys, firmware settings, recovery media and array rebuild plans. Use electrostatic-discharge precautions and never hot-remove unless the host documentation explicitly supports it.
