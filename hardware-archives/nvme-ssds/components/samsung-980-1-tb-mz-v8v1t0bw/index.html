Compatibility, installation & service

  • Check the board service manual for a 2280 M-key socket wired for PCIe/NVMe, UEFI NVMe boot and any shared lanes. A board thermal cover must fit without pressure and contact the SSD as intended. Record firmware/SMART and back up before firmware updates or migration. Peak vendor figures assume a suitable PCIe 3 x4 host and are not sustained-write guarantees.
  • The standard 980 is a DRAM-less client drive with Host Memory Buffer; do not confuse it with the PCIe 4.0 980 PRO already in the catalog. On a PCIe 4/5 host it negotiates at Gen3. Boot capability depends on motherboard UEFI NVMe support.
  • Confirm host boot mode, OS NVMe support, CPU lane generation, socket length/keying, power and controller/backplane qualification from the system manual; physical fit alone does not establish compatibility.
  • Before drive replacement, check backup integrity, encryption keys, firmware settings, recovery media and array rebuild plans. Use electrostatic-discharge precautions and never hot-remove unless the host documentation explicitly supports it.
