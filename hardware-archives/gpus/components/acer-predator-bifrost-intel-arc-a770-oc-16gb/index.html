Arc A770 belongs to Intel’s Xe-HPG Alchemist discrete graphics generation. The local GDDR6 configuration and PCIe link are part of the board record; actual negotiated PCIe speed and width are limited by the host slot, firmware and platform.

For a reliable deployment record, retain the exact board SKU, subsystem/device IDs, motherboard and firmware versions, driver package, operating system, PSU model and display connection path.
