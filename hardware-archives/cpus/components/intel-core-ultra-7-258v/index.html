Intel Core Ultra 7 258V

Lunar Lake (Core Ultra Series 2 V-series), 2024. 8 cores (4 P-cores + 4 low-power E-cores) / 8 threads; maximum turbo up to 4.80 GHz; 12 MB Intel Smart Cache; 17 W Processor Base Power; 37 W Maximum Turbo Power; FCBGA2833, soldered; memory is on-package; 32 GB on-package LPDDR5x-8533; not upgradeable or replaceable. Lunar Lake’s low-power design places the memory alongside the processor in its package; this 258V SKU has 32 GB LPDDR5x and eight CPU cores without Hyper-Threading.

MODEL IDENTIFICATION: Intel Core Ultra 7 258V. Confirm the complete model suffix and OEM board documentation; this is a soldered mobile package, not a universal replacement part.
