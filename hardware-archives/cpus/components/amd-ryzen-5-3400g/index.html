Platform and service notes

  • Socket: Socket AM4. A matching socket is necessary but not sufficient; board wiring, firmware, power delivery and OEM policy still govern compatibility.
  • Firmware: AM4 motherboard with a vendor CPU support list and BIOS explicitly supporting Ryzen 5 3400G / Picasso. Do not assume every AM4 board supports it; check board revision and firmware before installation. Always consult the board maker’s CPU support list for the exact board model/revision and BIOS version. Do not assume the installed BIOS can be upgraded with this CPU fitted.
  • Memory: Dual-channel DDR4, up to 2933 MT/s; supported speed depends on DIMM population and board firmware. Integrated GPU performance and stability depend on dual-channel memory configuration; check the board QVL and processor limits.
  • Expansion: PCI Express 3.0; usable graphics/storage lanes and slot routing are board-specific. Check board documentation for actual M.2/SATA sharing, slot electrical width and device-generation negotiation.
  • Do not infer discrete graphics outputs, display resolution or multi-monitor support from the GPU name alone; display connectors, firmware settings and board capability vary.
