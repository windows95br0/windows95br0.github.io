Intel Core i7-1360P

Raptor Lake (13th-generation Core P-series), 2023. 12 cores (4 P-cores + 8 E-cores) / 16 threads; maximum turbo up to 5.00 GHz P-core turbo; 18 MB Intel Smart Cache; 28 W Processor Base Power; 64 W Maximum Turbo Power; FCBGA1744, soldered; DDR4-3200, DDR5-5200, LPDDR4x-4267 or LPDDR5-6400; memory type is board-specific. Raptor Lake-P balances four performance and eight efficiency cores in a 28 W class notebook package; sustained behavior depends heavily on chassis tuning.

MODEL IDENTIFICATION: Intel Core i7-1360P. Confirm the complete model suffix and OEM board documentation; this is a soldered mobile package, not a universal replacement part.

Compatibility and service notes

  • Thin-and-light Raptor Lake-P systems designed for BGA1744. BIOS, board power limits, cooling and memory routing must match the exact OEM configuration.
  • DDR4-3200, DDR5-5200, LPDDR4x-4267 or LPDDR5-6400; memory type is board-specific Memory speed, channel wiring and any memory-on-package configuration must match the system-board design.
  • Check the laptop manufacturer's exact model-level CPU list, board revision, BIOS/firmware, thermal assembly and power profile. Package name alone does not guarantee electrical, firmware or mechanical compatibility.
  • PCI Express capabilities do not promise a particular connector, storage slot or external port; those are implemented by the notebook platform.
