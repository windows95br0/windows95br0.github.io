Intel Core i5-1135G7

Tiger Lake (11th-generation Core), 2020. 4 cores / 8 threads; maximum turbo up to 4.20 GHz; 8 MB Intel Smart Cache; 28 W base TDP; configurable down to 12 W; FCBGA1449, soldered; Dual-channel DDR4-3200 or LPDDR4x-4267; memory type and capacity depend on the laptop board. Tiger Lake paired four Willow Cove CPU cores with Xe-LP graphics and a mobile PCIe 4.0 connection; G7 identifies the high graphics tier.

MODEL IDENTIFICATION: Intel Core i5-1135G7. Confirm the complete model suffix and OEM board documentation; this is a soldered mobile package, not a universal replacement part.

Compatibility and service notes

  • Tiger Lake-U systems designed for the FCBGA1449 package. OEM firmware, cooling and platform power settings govern compatibility and sustained performance.
  • Dual-channel DDR4-3200 or LPDDR4x-4267; memory type and capacity depend on the laptop board Memory speed, channel wiring and any memory-on-package configuration must match the system-board design.
  • Check the laptop manufacturer's exact model-level CPU list, board revision, BIOS/firmware, thermal assembly and power profile. Package name alone does not guarantee electrical, firmware or mechanical compatibility.
  • PCI Express capabilities do not promise a particular connector, storage slot or external port; those are implemented by the notebook platform.
