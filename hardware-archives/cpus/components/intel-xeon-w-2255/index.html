Intel Xeon W-2255

Cascade Lake-W (Xeon W-2200 series), 2019. Exact model: Intel Xeon W-2255. 10 cores/20 threads; 3.70 GHz base / 4.50 GHz maximum turbo; 19.25 MB cache; 165 W TDP; LGA2066.

MODEL ID: Intel Xeon W-2255. Verify exact processor markings, board CPU qualification, BIOS and cooling before installation.

Compatibility and service

  • Require board-manufacturer confirmation for W-2255; earlier Xeon W-2100 support does not automatically mean W-2200 support.
  • Use quad-channel DDR4-2933 ECC memory listed by the board QVL; memory capacity and DIMM type depend on board population rules.
  • Size cooling and board power delivery for the 165 W TDP and sustained workloads.
  • No integrated graphics; a separate graphics adapter is needed for display.
