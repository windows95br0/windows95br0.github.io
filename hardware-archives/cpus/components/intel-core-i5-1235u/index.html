Intel Core i5-1235U

Alder Lake (12th-generation Core U-series), 2022. 10 cores (2 P-cores + 8 E-cores) / 12 threads; maximum turbo up to 4.40 GHz P-core turbo; 12 MB Intel Smart Cache; 15 W Processor Base Power; 55 W Maximum Turbo Power; FCBGA1744, soldered; DDR4-3200, DDR5-4800, LPDDR4x-4267 or LPDDR5-5200; board selects one memory type. Alder Lake-U hybrid design with two Hyper-Threaded performance cores and eight efficiency cores; the platform manages mixed DDR/LPDDR memory options.

MODEL IDENTIFICATION: Intel Core i5-1235U. Confirm the complete model suffix and OEM board documentation; this is a soldered mobile package, not a universal replacement part.

Compatibility and service notes

  • Alder Lake-U notebook platform with a compatible BGA1744 motherboard and BIOS. Soldered package, power envelope, cooling and memory layout are system-vendor choices.
  • DDR4-3200, DDR5-4800, LPDDR4x-4267 or LPDDR5-5200; board selects one memory type Memory speed, channel wiring and any memory-on-package configuration must match the system-board design.
  • Check the laptop manufacturer's exact model-level CPU list, board revision, BIOS/firmware, thermal assembly and power profile. Package name alone does not guarantee electrical, firmware or mechanical compatibility.
  • PCI Express capabilities do not promise a particular connector, storage slot or external port; those are implemented by the notebook platform.
