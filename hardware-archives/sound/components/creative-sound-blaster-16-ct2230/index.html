Creative Sound Blaster 16 (CT2230)

This record is limited to the CT2230-marked Sound Blaster 16 ISA board. CT2230 is a distinct board SKU; component substitutions and resource configuration must be checked against the actual card.

Model-specific specifications

Catalog identity / chipset / DSPCreative Sound Blaster 16 (CT2230). Creative Sound Blaster 16 DSP class (record the firmware revision reported by diagnostics); Yamaha YMF262 OPL3 FM synthesizer.
Audio codec / conversion16-bit ADC/DAC PCM path on the board; Creative production revisions vary in the analog codec implementation, so identify and photograph the codec IC rather than assigning one family-wide part number.
Bus / I/O / ports16-bit ISA. Typical SB16 base 220h, MPU-401-compatible MIDI 330h, OPL3 388h; ISA resources may be jumper/configuration dependent.
IRQLegacy IRQ selection is typically 5, 7, or 10; verify the CT2230 manual/jumper map and exclude motherboard-reserved lines.
DMA8-bit DMA typically channel 1; 16-bit DMA typically channel 5. Some board/configuration variants permit other channels; document actual setup.
Driver / operating systemCreative DOS initialization and diagnostic tools; Sound Blaster 16 DOS game interface. Windows 3.x/9x drivers are release- and board-dependent; no modern OS support is implied.
Motherboard compatibility16-bit AT ISA slot on a PC-compatible host; an 8-bit slot cannot provide the board’s full interface. Confirm physical clearance, resource sharing, BIOS ISA timing, and actual jumper map on legacy motherboards.
Sound standards / interfacesSound Blaster 16 PCM interface, AdLib/OPL3 music, and MPU-401 UART MIDI conventions; this card is not an AWE wavetable model.
Connectors / powerISA slot power; use only the analog, MIDI, CD-audio, and auxiliary connectors physically present on this exact board. Inspect the edge bracket, keyed headers, PCB revision, and manual before connecting.

Compatibility & preservation notes

This record is limited to the CT2230-marked Sound Blaster 16 ISA board. CT2230 is a distinct board SKU; component substitutions and resource configuration must be checked against the actual card. The precise DSP/codec package, firmware, resource assignment, and OS driver release must be matched to the physical SKU. Record the actual base port, IRQ, DMA channels, driver version, motherboard chipset, and BIOS configuration used in a working test rather than copying family defaults.

  • Photograph the complete model number, PCB revision, major IC markings, jumpers, connectors, and any daughterboard before service.
  • Check DMA and IRQ reservations against storage, serial/parallel, and other ISA devices; test PCM, synthesis, and MIDI functions independently.
  • Power down and unplug the host before fitting/removing ISA hardware. Keep the exact manual and original setup/driver media with the specimen.
