Yamaha AG06MK2

A streaming-oriented six-channel mixer that also provides stereo USB recording/playback, onboard effects, and loopback.

IDENTIFICATION: Manufacturer/model: Yamaha AG06MK2 6-channel mixer / USB audio interface. Verify the full model and hardware/firmware revision on the unit; similarly named generations may have different ports, drivers, or channel counts.

Specifications

Catalog subcategoryUSB audio interfaces
Model / SKU identityYamaha AG06MK2 6-channel mixer / USB audio interface; model-level identity, not a retailer bundle SKU.
Analog, digital I/O and host channelsThe mixer accepts two mono mic/line combo channels plus stereo line and mobile-device inputs; USB audio is 2-in/2-out at the host. Stereo monitor outputs and a headphone output are provided. This is not a multitrack 6-in USB interface.
Conversion, sample rate and bit depth24-bit; 44.1, 48, 88.2, 96, 176.4, and 192 kHz USB audio rates, subject to the selected host mode and application.
Mic preamps / phantom powerTwo mono mic/line channels with Yamaha D-PRE mic preamps; +48 V phantom power is provided on channel 1, and channel 2 supports Hi-Z input. Confirm the manual’s channel-specific input and phantom cautions.
USB generation / class complianceUSB-C connector; USB 2.0 audio transport. A second USB-C power input supports suitable external 5 V power; cable/host power requirements vary by setup.

Drivers, host compatibility & latency

  • Yamaha Steinberg USB Driver and AG Controller are available for supported Windows/macOS versions; class-compliant mode supports compatible mobile hosts. Check the rear-panel mode setting and OS-specific Yamaha download before use.
  • Loopback and hardware mixer monitoring support streaming workflows; USB stereo DAW round-trip latency still depends on driver, buffer, sample rate, and host load. Built-in DSP monitoring does not eliminate latency on computer-returned audio.
  • For predictable recording, match the interface and DAW sample rates, select the model-specific manufacturer driver where required, test the intended buffer under real session load, and retain a higher-buffer fallback for dense projects.

Identification and preservation notes

Photograph the underside model label and connector panel; record serial/model identifiers, revision, firmware, included power supply, optical mode, and installed driver version. Do not infer channel count or supported sample rate from a connector or product-family name alone.
