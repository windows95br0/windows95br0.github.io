[ IEEE 1394 CONTROLLER // EXPANSION CARDS ]

Delock 89305

PCIe FireWire card with two IEEE 1394b 800-Mb/s ports and one 1394a port. Verify the exact board label and revision before service.

MODEL SCOPE: Delock 89305. Specification distinctions below identify 1394a/1394b rates, physical bus and power limitations; host OS and driver support can change by revision and release.

Specifications and compatibility

Exact model / SKUDelock 89305
Controller chipsetTexas Instruments XIO2213B IEEE 1394 controller, per Delock product information.
PCI bus / lanesPCI Express x1.
IEEE 1394a rateIEEE 1394a / FireWire 400 support through the 6-pin port and bilingual 1394b ports, up to 400 Mb/s.
IEEE 1394b rateIEEE 1394b / FireWire 800, up to 800 Mb/s with compatible link partners and cables.
Ports and connectorsTwo external 9-pin 1394b connectors and one external 6-pin 1394a connector.
Power / bus-power notesThe 6-pin/bilingual connectors may carry bus power only as implemented by the card and supported by host supply; Delock’s cited product description does not establish a universal per-port current limit. No separate auxiliary power input is specified there.
OS driver compatibilityInstall the Delock-supported driver if the exact OS needs one; otherwise compatibility depends on an available OHCI 1394 driver. Confirm OS version and application support with the host vendor before relying on legacy devices.
Host compatibilityPCI Express x1 slot; verify bracket/clearance, device/cable generation and available OHCI driver. A PCIe slot is required; conventional PCI is not compatible.

Installation and archival notes

  • Match the card’s printed model/revision and connector layout to the cited maker documentation; do not infer a controller IC or current limit from the connector alone.
  • IEEE 1394 link rate is negotiated with the peripheral and cable. A FireWire 800 connector does not make a 400-Mb/s device or cable operate at 800 Mb/s.
  • Use ESD precautions; validate system bus wiring, driver version, peripheral power source, and application-level compatibility before replacing a working legacy host.
