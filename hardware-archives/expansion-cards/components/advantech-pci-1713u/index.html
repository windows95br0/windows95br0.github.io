[ INDIVIDUAL COMPONENT // ISOLATED ANALOG INPUT ]

Advantech PCI-1713U

32-channel isolated analog input acquisition on universal PCI, with 12-bit conversion and a 100 kS/s aggregate rate. This model-specific archival record separates published specifications from system-compatibility assumptions.

MODEL SCOPE: Advantech PCI-1713U. Confirm exact board label, revision, connector/accessory, firmware and host slot before installation.

Reference specifications

Exact modelAdvantech PCI-1713U
Host bus / lanes32-bit universal PCI; conventional PCI, not PCI Express. The universal-PCI implementation supports the PCI signaling-voltage families stated by Advantech. PCIe lanes: not applicable; this is a PCI model.
Channels, ranges and resolution32 single-ended or 16 differential analog input channels; 12-bit A/D conversion; maximum 100 kS/s aggregate. Selectable input ranges include ±10 V; verify range and wiring configuration in the manual. No analog-output function is claimed for this input-only model.
Isolation / safety ratingAdvantech specifies 2,500 VDC isolation for the PCI-1713U family. This is an isolation withstand figure, not a CAT installation rating or a substitute for system-level safety design.
Operating system and APIWindows: Advantech DAQNavi / device-driver API family; confirm the current driver matrix for the exact legacy PCI-1713U and operating-system release before deployment.
Compatibility notesUse the PCI-1713U manual to confirm channel grouping, common-mode limits and the supported terminal accessory. The original PCI-1713 and PCI-1713U are not interchangeable assumptions; check the full model label.

Compatibility, care & archival notes

  • Verify the full model suffix and revision against the manufacturer's manual; similarly numbered variants can change I/O functions.
  • Use a conventional PCI slot of supported voltage/keying; the card is not a PCIe x1/x4/x8/x16 device.
  • Record driver version, OS bitness, connector accessories, wiring and calibration state alongside any installation.
