Supermicro AOM-TPM-9670V-S

Supermicro vertical-orientation add-on Trusted Platform Module for supported Supermicro systems. The AOM prefix and matching motherboard option list matter: this is a platform TPM, not an independent crypto accelerator.

IDENTIFICATION: Confirm the printed part number, revision and host-board model. The connector, TPM generation, protocol transport and firmware support below are separate compatibility constraints.

Specifications and compatibility limits

Catalog subcategorySecurity coprocessors
Exact model / part identifierAOM-TPM-9670V-S
TPM protocol / command interfaceTCG TPM 2.0 command interface through the compatible Supermicro board header; no independent external protocol connector is provided.
Physical connector / transportSupermicro motherboard TPM header for the V-S module form. Confirm the documented 10-pin header wiring/orientation and board revision; do not interchange with horizontal modules or third-party headers based only on pin count.
Host compatibility limitOnly Supermicro motherboard/server combinations listed for AOM-TPM-9670V-S, with the appropriate TPM header and firmware support. Compatibility does not extend to generic desktop boards.
Firmware / OS compatibility limitTCG 2.0 functions require the supported Supermicro BIOS/UEFI and OS TPM stack. Platform firmware controls visibility and provisioning; use only the board-specific firmware/update and security procedures.

Installation, firmware and archival notes

  • Before installation, record the module label/revision, host motherboard or server model, board revision, BIOS/UEFI version and TPM mode. Check the host’s own support list and installation diagram.
  • Use ESD precautions and the documented module orientation. A physically fitting header may have different LPC/SPI signaling, pinout or voltage; never hot-plug a motherboard TPM module.
  • TPM clear, replacement, firmware changes or mode changes can invalidate keys sealed to the previous TPM state. Back up recovery keys and follow the platform owner’s documented recovery procedure before service.
  • This is a TPM, not a general-purpose cryptographic coprocessor or HSM: do not assume it offers PCIe/USB/network connectivity or vendor-specific bulk crypto APIs.

Where a manufacturer no longer publishes a current manual, preserve the source revision and verify the hardware against the original host platform before use.
