Magewell Pro Capture HDMI 4K Plus

Single-channel HDMI 2.0 PCIe capture card for high-frame-rate UHD and DCI video ingest. This is a model-specific reference; verify the board revision and full specifications against the official sources before installation.

IDENTIFICATION: Match the silkscreen/model marking, part number, board revision and bracket to manufacturer documentation. Port direction, supported formats and driver behavior can vary by model revision and software release.

Capture, playback and compatibility specifications

Exact modelPro Capture HDMI 4K Plus
Bus / host interfacePCI Express 2.0 x4 host card; ensure the slot has four lanes and the system can sustain the selected uncompressed stream.
Capture / playback interfaceOne HDMI 2.0 input with embedded digital audio; capture-only. HDMI source timing, color format and EDID must be supported by the card and driver.
Resolution and frame-rate envelopeUp to 4096×2160 at 60 frames/s for supported HDMI timings, plus lower SD/HD/2K/UltraHD formats. Maximums depend on pixel format, input timing and driver mode.
Pixel format and codec handlingCaptures uncompressed video frames in supported RGB/YUV formats (including 8/10-bit paths where the input/driver allows). It does not encode files onboard; recording to H.264/HEVC/ProRes or another codec is performed by host software.
Host compatibilityUse Magewell’s supported Windows/Linux driver and a compatible DirectShow, Media Foundation, V4L2 or SDK application; validate current OS/driver and PCIe requirements against its downloads page.
Limitations and installation checksHDCP-protected HDMI content is not available as a normal capture source. HDMI cable quality, EDID, color range, 4:2:2/4:4:4 mode and aggregate PCIe/storage bandwidth affect capture. One HDMI input; no SDI or standalone file recording.

Integration notes and limitations

  • Measure available PCIe lanes and sustained host/storage bandwidth; mechanical slot length alone does not guarantee the electrical link width needed by the card.
  • Confirm that source timing, signal standard, cable, reference, pixel format, channel mapping and software configuration agree before recording or playback.
  • Record driver/firmware versions, operating system, application, breakout/accessory part numbers and tested mode. Update only with a recovery plan for mission-critical rigs.
  • HDCP-protected HDMI content is not available as a normal capture source. HDMI cable quality, EDID, color range, 4:2:2/4:4:4 mode and aggregate PCIe/storage bandwidth affect capture. One HDMI input; no SDI or standalone file recording.

For codec planning, distinguish a video transport/interface and raw pixel format from a compressed media-file codec. A supported capture application may encode a file format that the card itself does not encode.
