Advantech PCI-1711

16 single-ended analog inputs, 12-bit conversion and 100 kS/s aggregate sampling, with analog output and TTL digital I/O. This model-specific archival record separates published specifications from system-compatibility assumptions.

MODEL SCOPE: Advantech PCI-1711. Confirm exact board label, revision, connector/accessory, firmware and host slot before installation.

Reference specifications

Exact modelAdvantech PCI-1711
Host bus / lanes32-bit PCI (PCI 2.1); conventional PCI, not PCI Express. PCIe lanes: not applicable; this is a PCI model.
Channels, ranges and resolution16 single-ended analog inputs (or 8 differential), 12-bit A/D, up to 100 kS/s aggregate; selectable input ranges through ±10 V. PCI-1711 includes two 12-bit analog outputs; 16 digital inputs, 16 digital outputs and two 16-bit counters. The PCI-1711L omits analog output and is not this record.
Isolation / safety ratingNo galvanic isolation specified for the standard PCI-1711; do not treat it as an isolated measurement front end.
Operating system and APIWindows: Advantech DAQNavi / device-driver API family; legacy-board and OS-version support must be confirmed in the current model driver matrix. The hardware manual documents register and driver-level programming.
Compatibility notesConfirm the suffix: PCI-1711 and PCI-1711L differ in analog-output capability. Use the model-specific terminal board and observe input common-mode limits. Fit only a compatible conventional PCI slot.

Compatibility, care & archival notes

  • Verify the full model suffix and revision against the manufacturer's manual; similarly numbered variants can change I/O functions.
  • Use a conventional PCI slot of supported voltage/keying; the card is not a PCIe x1/x4/x8/x16 device.
  • Record driver version, OS bitness, connector accessories, wiring and calibration state alongside any installation.
