[ IEEE 1394 CONTROLLER // EXPANSION CARDS ]

StarTech PEX1394A2V

2-port PCIe FireWire 400 adapter with two external 6-pin IEEE 1394a ports. Verify the exact board label and revision before service.

MODEL SCOPE: StarTech PEX1394A2V. Specification distinctions below identify 1394a/1394b rates, physical bus and power limitations; host OS and driver support can change by revision and release.

Specifications and compatibility

Exact model / SKUStarTech PEX1394A2V
Controller chipsetStarTech identifies the OHCI FireWire controller family; the public PEX1394A2V listing does not identify a silicon part number. Verify the board/revision PCI ID instead of inferring a chip.
PCI bus / lanesPCI Express x1 (single lane).
IEEE 1394a rateIEEE 1394a / FireWire 400, up to 400 Mb/s per link.
IEEE 1394b rateNot a 1394b / FireWire 800 adapter.
Ports and connectorsTwo external 6-pin IEEE 1394a connectors.
Power / bus-power notes6-pin connectors can carry FireWire bus power subject to the card’s implementation and host power budget. No separate auxiliary card-power input is identified in the cited listing; use 4-pin peripheral cables only for data.
OS driver compatibilityOHCI-class IEEE 1394 driver support is operating-system/release dependent. Check StarTech’s driver/support page for the exact OS; do not assume legacy FireWire applications or modern OS releases are supported.
Host compatibilityRequires a PCIe x1 slot (or a longer compatible PCIe slot wired to support it); not compatible with conventional PCI slots. Confirm firmware/OS OHCI support and device power needs.

Installation and archival notes

  • Match the card’s printed model/revision and connector layout to the cited maker documentation; do not infer a controller IC or current limit from the connector alone.
  • IEEE 1394 link rate is negotiated with the peripheral and cable. A FireWire 800 connector does not make a 400-Mb/s device or cable operate at 800 Mb/s.
  • Use ESD precautions; validate system bus wiring, driver version, peripheral power source, and application-level compatibility before replacing a working legacy host.
