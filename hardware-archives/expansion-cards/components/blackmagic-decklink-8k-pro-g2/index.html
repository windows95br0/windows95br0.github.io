Blackmagic Design DeckLink 8K Pro G2

High-end multi-link SDI capture and playback card for 8K, 4K and HD post-production. This is a model-specific reference; verify the board revision and full specifications against the official sources before installation.

IDENTIFICATION: Match the silkscreen/model marking, part number, board revision and bracket to manufacturer documentation. Port direction, supported formats and driver behavior can vary by model revision and software release.

Capture, playback and compatibility specifications

Exact modelDeckLink 8K Pro G2
Bus / host interfacePCI Express x8 card; install in a compatible slot with eight lanes and adequate airflow. Check the Desktop Video system requirements for the host OS and application.
Capture / playback interfaceFour bidirectional 12G-SDI connections plus HDMI 2.1 support capture and playback workflows; direction, link grouping and reference are configured in Desktop Video and supported applications.
Resolution and frame-rate envelopeSD/HD/2K/4K/UltraHD and 8K formats; maximum frame rate depends on raster, channel/link mapping, bit depth and software. Use the manufacturer’s DeckLink format table for exact DCI/UHD timing and HDMI/SDI limits.
Pixel format and codec handlingSupports professional uncompressed video workflows through Desktop Video/SDK (including 10-bit YUV and supported RGB formats). It is not a standalone file encoder: ProRes, DNx and compressed media depend on host software and storage.
Host compatibilityBlackmagic Desktop Video and compatible editing/broadcast software are required. Confirm current macOS/Windows/Linux support, host slot generation/lanes and supported application version in Blackmagic’s downloads and release notes.
Limitations and installation checks8K requires multiple SDI links and high sustained I/O; not every combination of ports, raster, frame rate and pixel format is concurrent. Match quad-link mapping and reference; HDCP content is not captured through a protected path.

Integration notes and limitations

  • Measure available PCIe lanes and sustained host/storage bandwidth; mechanical slot length alone does not guarantee the electrical link width needed by the card.
  • Confirm that source timing, signal standard, cable, reference, pixel format, channel mapping and software configuration agree before recording or playback.
  • Record driver/firmware versions, operating system, application, breakout/accessory part numbers and tested mode. Update only with a recovery plan for mission-critical rigs.
  • 8K requires multiple SDI links and high sustained I/O; not every combination of ports, raster, frame rate and pixel format is concurrent. Match quad-link mapping and reference; HDCP content is not captured through a protected path.

For codec planning, distinguish a video transport/interface and raw pixel format from a compressed media-file codec. A supported capture application may encode a file format that the card itself does not encode.
